Preguntas frecuentes

¿Es gratis?

Sí. La compilación usa GitHub Actions y el proyecto es open source.

¿Puedo publicar en Google Play?

Sí. Marca el chip AAB en el paso 3, firma con tu keystore y sube el bundle a Play Console.

¿Qué pasa con mis datos?

La rama con tu código se borra al terminar el build (no queda código en el repo). Artefactos y runs se auto-limpian después. Ver Política de Privacidad.

¿Funciona sin programar?

Sí. Plantillas y presets configuran todo por ti; el modo avanzado es opcional.

Formatos de salida

Cada build entrega además los archivos PWA (manifest.webmanifest + sw.js). EXE / DMG / AppImage / MSI se compilan de verdad en GitHub Actions (Windows, macOS y Ubuntu) y añaden ~2-4 min al build; en macOS salen sin firma de Apple, así que Gatekeeper avisará al abrirlos. El destino Win/Mac lo fija el selector "Destinos escritorio" de este mismo paso.

iOS: sin firma solo se valida en simulador. Para el chip IPA (y un .ipa instalable) sube tu .p12 + .mobileprovision en Firma.

Audio 100% nativo PRO

El audio lo reproduce Java nativo (MediaPlayer en foreground service), no el WebView. Tu HTML es solo la cara con botones que llaman window.InteeAudio.play(url). Se activa solo con las plantillas Radio y Streaming.
